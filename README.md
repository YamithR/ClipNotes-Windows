# ClipNotes-Windows

Copia notas de texto al portapapeles desde la bandeja del sistema. Puerto a Windows de [gnome-extension-copier](https://github.com/hedgieinsocks/gnome-extension-copier).

## Características

- Icono en la bandeja del sistema
- Navegación por carpetas de notas
- Copia el contenido de archivos de texto al portapapeles con un clic
- Opción para ocultar extensiones de archivo
- Instalador MSI para Windows

## Instalación

Descarga el instalador MSI desde [Releases](https://github.com/YamithR/ClipNotes-Windows/releases) o construye desde código:

```bash
npm install
npm run build:win
```

## Desarrollo

```bash
npm install
npm start
```
